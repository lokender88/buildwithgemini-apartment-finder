# My agent: Apartment Finder Agent
One-liner: A conversational agent that helps apartment seekers find, evaluate, and compare rental properties with a catalog of local listings and personalized preferences.

Tool coverage:
- Memory: Remembers user budget, preferred neighborhoods, move-in dates, and desired amenities (pets, parking, laundry).
- Tools: Look up available apartment listings, filter by price/amenities, and schedule viewing appointments.
- Catalog/UI: Collection of rental property listings rendered as comparison cards and tables.
- Image gen: Generates visual room layout visualizations or exterior views for listings.
- Sandbox: Calculates total monthly cost (rent + estimated utilities + parking) and upfront move-in costs.

Core rails (everyone): memory, tools, eval, deploy, frontend
My stretch menu (pick later): A2UI card formatting, image generation, sandbox financial calculations
First eval question: Find 2-bedroom apartments under $2,500/month in Midtown that allow dogs and calculate total move-in cost.
